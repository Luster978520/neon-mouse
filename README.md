# NeonMouse 2.1 · 荧光鼠标拖尾

Windows 桌面荧光鼠标拖尾工具，带可视化参数面板、动态预览和自动保存。独立运行，不需要安装，也不依赖其他项目。

## 启动与退出

1. 双击 `NeonMouse.exe`，自动打开设置面板并启用桌面拖尾。
2. 拖动滑块，效果即时应用到桌面；面板顶部的动态预览也会随参数变化。
3. 点击“隐藏到托盘”或关闭面板，拖尾继续运行。
4. 双击系统托盘图标，或右键选择“打开设置面板”，可再次调整。
5. 右键托盘选择“退出荧光拖尾”，或在面板中点击“退出程序”，才会结束程序。

重复打开 EXE 会唤回已有设置面板，不启动第二份效果。

## 可调参数

| 参数 | 范围 / 选项 | 作用 |
| --- | --- | --- |
| 拖尾样式 | 经典荧光线条 / 心动爱心 | 在线条和发光爱心粒子之间切换 |
| 拖尾时长 | 0.10～1.50 秒 | 值越大，轨迹保留越久 |
| 轨迹粗细 / 爱心大小 | 线宽 1.0～12.0 px；爱心约 10～34 px | 随样式切换，调整线条宽度或爱心尺寸 |
| 整体亮度 | 10%～100% | 调整所有发光层的透明度 |
| 柔光范围 | 0%～200% | 调整外层光晕宽度，0% 关闭外层光晕 |
| 淡出强度 | 1.0～4.0 | 值越大，尾部越快变透明 |
| 变色周期 | 4～60 秒 | 彩虹模式下，完成一次颜色循环的时间 |
| 颜色模式 | 流动彩虹 / 固定颜色 | 固定颜色模式中可打开颜色选择器 |
| 刷新模式 | 流畅 / 省电 | 目标约 60 / 30 FPS，实际取决于系统和负载 |
| 启用荧光拖尾 | 开 / 关 | 临时暂停或恢复效果 |
| 拖选时隐藏 | 开 / 关，默认开 | 按住鼠标主键时清空轨迹，避免遮住选取文字 |

保留原有 0.48 秒时长、4.2 px 主体宽度作为默认参数。“恢复默认”会重置全部参数，包括重新开启拖选保护。

### 心动爱心

在“拖尾样式”中选择“心动爱心”。移动鼠标时会沿路径依次出现带光晕的爱心和小闪光，随后轻微上浮、缩小并淡出。爱心按移动距离生成，既有粒子不会随着鼠标继续移动而整串滑动。

心形与线条共用时长、亮度、柔光、淡出和颜色参数。喜欢粉色效果时，可将“颜色模式”设为“固定颜色”，选择粉色（例如 `#FF5CA0`）。旧配置文件可以继续使用，缺少样式字段时默认使用经典线条。

![粉色心动爱心效果示意](heart-preview.png)

拖尾可以正常经过设置面板所在区域，包括面板被其他应用覆盖时。松开鼠标主键时会重置轨迹起点，不会补画拖选期间的轨迹。支持 Windows 中左右键互换的设置。

## 保存设置

调整后约 0.6 秒自动保存，也可以点击“保存设置”。配置文件是程序同目录下的 `settings.xml`，下次启动自动恢复。不修改系统鼠标设置，不注册开机启动。

请把程序放在有写入权限的文件夹内。保存失败时面板底部会显示错误；当前会话的实时效果仍可使用。配置文件损坏时程序使用默认值，并在面板提示。

## 源代码与编译

- `NeonMouse.cs`：应用入口、单实例唤回、透明桌面覆盖层、轨迹绘制和托盘菜单。
- `Settings.cs`：设置模型、XML 读写、参数面板和动态预览。
- `build.ps1`：使用 Windows 本机 .NET Framework 编译器构建，无需下载依赖。
- `app.ico`：应用图标，编译时嵌入 EXE，同时用于设置窗口和系统托盘；运行时无需单独读取图标文件。

先退出正在运行的 NeonMouse，再在本文件夹的 PowerShell 中运行：

```powershell
.\build.ps1
```

也可以直接执行编译命令：

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe /optimize+ /codepage:65001 /reference:System.Drawing.dll /reference:System.Windows.Forms.dll /reference:System.Xml.dll /win32icon:app.ico /resource:app.ico,NeonMouse.App.ico /out:NeonMouse.exe NeonMouse.cs Settings.cs
```

## 使用范围

适用于有 .NET Framework 4.x 的 Windows 桌面和普通窗口。不需要管理员权限，不联网，不安装驱动。独占全屏游戏、锁屏和 UAC 安全桌面可能无法显示效果。多显示器混合缩放和游戏兼容性仍需在实际环境确认。

退出后删除本文件夹即可移除程序和本地设置。`preview.png` 是轨迹效果的静态示意图，实际桌面覆盖层背景透明。
