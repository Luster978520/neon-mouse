# 本机荧光鼠标拖尾

双击 NeonMouse.exe 即可运行。适用于有 .NET Framework 4.x 的 Windows 桌面；本机已成功编译并做过启动检查。

## 使用

- 启动后，移动鼠标即可看到发光轨迹。
- 在任务栏右侧系统托盘找到程序图标，右键可选择“暂停 / 继续”或“退出荧光拖尾”。图标可能在向上的箭头里。
- 重复打开不会启动第二个实例。
- 按住鼠标主键（通常是左键）时，立即隐藏并清空拖尾，避免遮住拖选的文字、框选区域或正在拖动的东西。松开时重置轨迹起点，随后移动鼠标恢复效果；不会补画选取过程中的轨迹。也支持系统设置中左右键互换的鼠标。
- 退出后效果立即消失。不需要管理员权限，不注册开机启动。

## 默认效果

- 大约 60 FPS 的目标刷新速度，实际取决于系统负载。
- 轨迹约 0.58 秒后消失。
- 越接近鼠标越粗、越亮；越靠近尾部越细、越透明。
- 外层柔光、彩色主体、浅色亮芯叠加；颜色大约每 18 秒循环一周，沿轨迹有渐变。
- 窗口使用逐像素透明、鼠标穿透和禁止激活样式，避免遮挡点击和抢走键盘焦点。

## 原理与调整

程序定时读取鼠标屏幕坐标，保存短时间内的轨迹点。在小型置顶透明窗口中，用四层不同宽度和透明度的线条绘制轨迹。每个点的年龄决定线宽和透明度，色相随时间和轨迹位置变化。绘制窗口随轨迹范围调整，避免每帧绘制整个桌面。

源代码是 NeonMouse.cs：

- `Lifetime = 0.58`：调大后轨迹更长，调小后消失更快。
- `StrokeWidth = 4.2f`：调大后轨迹更粗。
- `timer.Interval = 16`：目标刷新间隔，单位毫秒。
- `Hue(now * 0.055 ...)` 中的 `0.055`：调大后颜色切换更快。

修改后，在 Windows PowerShell 中进入本目录并执行下面的编译命令。先退出正在运行的工具。

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe /optimize+ /codepage:65001 /reference:System.Drawing.dll /reference:System.Windows.Forms.dll /out:NeonMouse.exe NeonMouse.cs
```

## 使用范围

这是 Windows 桌面覆盖层，通常可用于桌面和普通窗口。独占全屏游戏、锁屏、UAC 安全桌面等场景可能不显示。不同缩放比例的多显示器配置和游戏兼容性仍需要在实际使用环境中确认。

该工具不联网、不安装驱动、不修改系统鼠标设置。若不再使用，退出后删除文件夹即可。
